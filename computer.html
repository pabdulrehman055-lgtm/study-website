💻 Computer Science Notes

🖥️ Computer Basics

What is a Computer?

A computer is an electronic device that accepts data, processes it, and produces useful information.

Hardware

Hardware means the physical parts of a computer, such as keyboard, mouse, monitor and CPU.

Software

Software is a set of programs and instructions that tells a computer what to do.

⚙️ Operating System

What is an Operating System?

An operating system is software that manages computer hardware and allows users to run applications.

Examples

Windows, Linux, macOS, Android and iOS are examples of operating systems.

🌐 Internet Basics

What is the Internet?

The Internet is a global network that connects computers and devices around the world.

Web Browser

A web browser is software used to access websites, such as Chrome, Edge and Firefox.
