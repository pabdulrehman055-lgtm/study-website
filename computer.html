Computer Basics

What is a Computer?

A computer is an electronic device that accepts data, processes it, and produces useful information.

Hardware

Hardware means the physical parts of a computer, such as keyboard, mouse, monitor and CPU.

Software

Software is a set of programs and instructions that tells a computer what to do.
