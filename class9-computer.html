💻 Class 9 Computer Science Notes

🖥️ Computer Basics

What is a Computer?

A computer is an electronic machine that accepts data, processes it and produces information.

Hardware

Hardware means the physical parts of a computer, such as keyboard, mouse, monitor and CPU.

Software

Software is a set of programs that tells a computer what to do.

🌐 Internet Basics

Internet

The Internet is a worldwide network that connects computers and devices.

Web Browser

A web browser is software used to access websites. Examples include Chrome, Firefox and Edge.

Website

A website is a collection of web pages available on the Internet.

📘 Chapter 1: Computer Fundamentals

Data and Information

Data is a collection of raw facts and figures. Information is processed data that has meaning.

Input Devices

Input devices are used to enter data into a computer. Examples include keyboard, mouse and scanner.

Output Devices

Output devices show or produce the results of computer processing. Examples include monitor, printer and speakers.

📗 Chapter 2: Operating Systems

What is an Operating System?

An operating system is system software that manages computer hardware and provides services for applications.

Examples

Windows, Linux, macOS, Android and iOS are examples of operating systems.

🌐 Chapter 3: Internet

Internet

The Internet is a worldwide network that connects computers and other devices.

Web Browser

A web browser is software used to access and view websites on the Internet.
